# 界面语言

Zagens 桌面 UI 支持四种语言，与 Agent 回复语言无关（回复由你的 prompt 与模型决定）。

## 支持的语言

| 语言 | 代码 |
|------|------|
| 简体中文 | `zh-Hans` |
| English | `en` |
| 日本語 | `ja` |
| Português (Brasil) | `pt-BR` |

## 如何切换

1. 侧栏 → **设置** → **系统**（System）
2. **外观（Appearance）** → **语言（Language）**
3. 选择后立即生效，无需重启

侧栏底部也有快捷 **主题 / 语言** 切换（与系统面板同步）。

## 与文档站的关系

本帮助站提供 **简体中文** 与 **English** 产品文档；应用内 UI 另含日语与巴西葡萄牙语。

## 说明

- 菜单、按钮、设置标签随 UI 语言变化
- 内置办公技能与 `SKILL.md` 正文多为中文；可在对话中用英文 prompt
- 错误信息与 runtime 日志可能仍为英文
