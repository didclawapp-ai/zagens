# 审批对话框

当工具调用被判定为有风险时，Zagens 会暂停并弹出**桌面原生审批框**（非 WebView 内嵌）。

## 界面内容

- 工具名称与操作摘要（shell、写文件、网络请求等）
- **批准** / **拒绝**
- 约 **120 秒**默认超时 — 超时视为拒绝

## 常见触发

- 超出安全前缀字典的 shell 命令
- 策略为 `untrusted` / `on-request` 时的写入
- 网络域名首次访问且模式为 `prompt`

在[工具审批](/zh-Hans/docs/settings/approval)与**系统**执行策略中配置。

## 流式过程中

聊天流式输出会暂停，直至你选择；其余 UI 仍可操作。

## 会话记忆

同类安全操作批准一次后，可能**本会话自动通过**。

## 建议

- 对话框可能被主窗口挡住 — 注意任务栏闪烁。
- 对过于宽泛的命令（如删系统目录）请拒绝并改写目标。
