# 系统托盘与通知

Zagens 在 Windows 上作为桌面应用运行，任务栏有**系统托盘**图标。

## 托盘行为

- 最小化或关闭窗口后，可按系统设置继续在托盘运行
- 点击托盘图标恢复主窗口
- 从托盘菜单完全退出可结束 runtime 侧车

## 回合完成通知

Agent 长任务在**后台**完成时，可弹出原生 **Toast 通知**（取决于桌面壳设置）。

适合办公 DOCX 生成或代码模式跑测试等耗时回合。

## Runtime 侧车

托盘反映应用进程；实际推理仍经本地 **runtime 侧车**（`127.0.0.1`）。若回合无响应，查看侧栏连接状态。

## 建议

- 若从未收到通知，在 Windows 设置中允许 Zagens 通知。
- 无人值守运行需保持机器唤醒且 API Key 有效。
