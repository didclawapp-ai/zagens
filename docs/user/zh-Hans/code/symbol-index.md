# 符号索引

**Index** 面板维护工作区级**符号索引**，加速代码模式下的 `grep_files` 与符号检索。

## 打开面板

侧栏 → **Index**（仅代码会话）。显示状态、文件数、体积与上次重建时间。

## 状态

| 状态 | 含义 |
|------|------|
| **Fresh** | 与当前工作区一致 |
| **Stale** | 文件已变 — 建议重建 |
| **Missing** | 尚无索引 — 首次搜索或手动重建时生成 |

## 操作

- **Rebuild** — 全量重扫（大仓库可能较久）
- **Delete** — 删除缓存；下次搜索自动重建
- **Open folder** — 在资源管理器中打开索引目录

索引缓存文件位于工作区 **`.deepseek/symbols.json`**（按工作区 lazy 构建）。

## 适用场景

- 在 monorepo 中跳转定义
- `grep_files` 结合符号过滤，而非纯文本

办公模式**不使用**符号索引。

## 建议

- 大合并或依赖更新后重建。
- 搜索结果异常时可删除索引，让下一回合自动重建。
