# 项目汇报 PPT

**技能：** `office-project-report` · **输出：** PPTX

## 作用

制作项目状态汇报幻灯片：进展、风险与下一步。

## 开始前

- 任务类型：**办公**
- 可选：`inbox/` 中的状态文档或旧版 PPT（DOCX、PPTX、Markdown）

## 如何运行

1. 点击**项目汇报 PPT**或输入：
   > 做一份项目状态汇报 PPT，先确认项目名和听众。
2. 提供：项目名、汇报人、听众、日期、关键里程碑。
3. 在 `deliverables/` 用 PowerPoint 或办公预览打开 PPTX。

## 典型幻灯片

**封面** · 进展要点 · 风险与缓解 · 下一步计划

## 验收

- 封面含项目名与汇报人
- 风险页有具体缓解措施，非空泛占位

## 建议

- 无文件时可对话提供一段状态摘要。
- 可追加：「加一页预算」— Agent 通过 `load_office_payload` 增量修改。
