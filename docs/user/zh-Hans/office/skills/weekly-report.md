# 周报

**技能：** `office-weekly-report` · **输出：** DOCX

## 作用

根据你的笔记或附件撰写周报：本周完成、下周计划、风险与阻塞。

## 开始前

- 任务类型：**办公**
- 可选：进展说明、工单或表格放在 `inbox/` 或 `data/`

## 如何运行

1. 点击空态**周报**卡片，或输入：
   > 写本周工作周报，先确认时间范围和汇报对象。
2. 提供：汇报周期、对象（上级/团队）、本周完成、下周计划、风险。
3. Agent 用 `read_office` 读附件后，将 DOCX 写入 `deliverables/`。

## 典型章节

**本周完成** · **下周计划** · **风险与阻塞**

## 验收

- 三节齐全
- 标题周次与日期符合要求

## 建议

- 暂无文件时可直接在对话里列要点。
- 可追问修改：「补充供应商延迟风险」— Agent 可覆盖同一路径文件。
