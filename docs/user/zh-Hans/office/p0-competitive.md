# P0-1：竞品 / 行业动态

**技能：** `office-competitive-analysis` · **输出：** 含来源列表的 DOCX

## 做什么

联网调研竞品或行业动态，对比整理后交付结构化简报，而不是聊天摘要。

## 准备工作

- 任务类型：**办公**
- 可选：将参考笔记放入 `inbox/`
- 需可访问 `web_search` / `fetch_url`

## 如何运行

1. 打开 Zagens，选择**办公**并选定工作区。
2. 在空态点击 **竞品分析**，或粘贴类似目标：
   > 调研竞品 A、B 在欧洲市场近期动态，交付含来源的 DOCX。
3. 回答澄清问题（对象、时间范围、对比维度）。
4. 回合结束后在 `deliverables/` 查看 DOCX。

## 典型章节

摘要 · 竞品对比 · 优劣势 · 建议 · **来源**（标题、URL、日期）

## 验收

- 来源列表完整、链接可信
- 无编造价格或日期
