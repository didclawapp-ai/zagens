# 办公模式

**办公**任务类型是面向文档工作的本地桌面副驾：读表、联网检索，并交付 **DOCX、XLSX、PPTX 或 PDF**，而不是在聊天框里贴一段文字。

## 工作区结构

详见[办公工作区](/zh-Hans/docs/office/workspace)（`inbox/` · `data/` · `deliverables/`）与[交付物预览](/zh-Hans/docs/office/deliverables)。

办公会话侧栏会隐藏**路由**、**话题记忆**、**符号索引**、**LHT 设置**等代码向入口。
