# P0-3：生产 / 品质晨报

**技能：** `office-production-daily-report` · **输出：** 先文字概况，再 DOCX（可选 XLSX）

## 做什么

根据生产与品质导出表，生成面向现场负责人的晨报 — 指标、异常与跟进项。

## 准备工作

- 任务类型：**办公**
- 将昨日 MES 或 Excel 导出放入 **`data/`**（如 `data/生产日报_昨日.xlsx`）
- 演示 fixtures 含生产/品质示例表

## 如何运行

1. 空态点击 **生产/品质晨报**，或说明：
   > 汇报昨日生产与品质情况，先给文字概况，再出 DOCX。
2. 阅读 Agent 先输出的短摘要。
3. 确认后生成完整 DOCX 到 `deliverables/`。

## 典型章节

概况 · 生产指标 · 品质指标 · 异常与风险 · 待确认事项

## 验收

- 指标可追溯到 `data/` 上传表格
- 含 **OEE / 良率** 等关键指标（与源表一致）
- 先文字概况、确认后再出 DOCX
