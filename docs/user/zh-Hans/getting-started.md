# 快速开始

Zagens 是面向 DeepSeek V4 生态的**桌面 Agent Harness**。同一应用覆盖聊天、编码与文档工作流，并按任务类型切换工程向与办公向工具面。

## 准备工作

- Windows 10/11 x64
- [DeepSeek API Key](https://platform.deepseek.com/)
- 用作工作区的文件夹（代码仓库或办公 inbox）

## 首次启动

1. 从[下载页](/zh-Hans/download)获取最新安装包。
2. 若 SmartScreen 拦截未签名安装包，请参阅[安装指引](/zh-Hans/install)。
3. 打开 Zagens（当前版本 **v0.7.0**），填入 API Key，选择**任务类型**：
   - **代码** — 终端、diff、重构、测试
   - **办公** — 读表、联网检索，交付 DOCX / XLSX / PPTX / PDF

   选型说明见[任务类型](/zh-Hans/docs/task-types)。
4. 为会话选择**工作区目录**。

## 熟悉界面

首次使用？阅读[界面导览](/zh-Hans/docs/ui-tour)，了解侧栏、对话区、工作区面板与审计网格。
