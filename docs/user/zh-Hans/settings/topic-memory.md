# 话题记忆图

**Topic memory** 在多回合中归纳主题关系，并将相关片段注入后续上下文。

## 启用

**设置 → 系统 → 高级 → Topic memory**（可设**注入间隔**回合数）。

办公会话隐藏话题记忆侧栏。

## 图面板

侧栏 → **Topic memory** 显示节点（主题）与加权边。布局限制可见节点数以对齐运行时注入上限。

## 行为

- 引擎从对话中提取主题
- 每 N 回合（间隔设置）可能将相关摘要写入系统上下文
- 与可选**用户记忆**（`remember` 工具）互补 — 话题记忆自动建图，非手动笔记

## 建议

- 长调研线程间隔可设 **5–10**。
- 一次性短问可关闭以省 token。
- 不能替代仓库 `AGENTS.md` — 稳定事实请写进文件。
