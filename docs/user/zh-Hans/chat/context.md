# 上下文用量

长对话会占满模型**上下文窗口**。Zagens 展示占用并可在后台自动压缩历史。

## 上下文条

输入区附近的**上下文条**估算当前线程占用 — 历史、工具结果与附件计入窗口。

压力高时可能建议压缩或开新会话。

## 压缩

Runtime 可按配置（L1/L2/L3）摘要或裁剪较早回合，尽量保留近期内容与关键工具输出。一般无需手动操作。

## 长任务建议

- 换题时开**新会话**。
- 代码模式的多小时任务用 [LHT](/zh-Hans/docs/code/lht)，避免单聊天堆到底。
- 大日志放进工作区文件，让 Agent 分段 `read_file`。

## 办公模式

单次交付通常较短。若在同一 DOCX 上多轮迭代，可每版 `write_office` 确认后再继续。
