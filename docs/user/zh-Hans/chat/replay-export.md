# 回放与导出

查看 Agent 历史行为，或导出线程用于排查。

## 回合回放

**回放**按回合展示：用户消息、助手文本、工具调用与输出。适合审计实际执行了什么。

在会话 UI 中打开已完成或暂停线程的回放。

## 导出 JSON

在 **Composer 菜单**：

- **导出会话 JSON** — 会话元数据与线程
- **导出线程 JSON** — 单线程载荷

可用于反馈问题、回归或归档。可能含工作区路径与工具输出 — 外发前请脱敏。

## 导出不能替代

- 不备份工作区文件本身 — 请用 git 或复制 `deliverables/`。
- 当前版本不以 JSON 再导入为主要工作流。

## 隐私

导出可能含 API 相关元数据与文件片段，分享前请处理敏感信息。
