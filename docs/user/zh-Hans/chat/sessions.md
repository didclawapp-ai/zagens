# 会话管理

Zagens 以**会话**（对话）组织工作，每个会话绑定一个工作区。

## 侧栏

- **新对话** — 在当前工作区开启新线程
- **会话列表** — 继续该文件夹下的历史对话
- **显示全部会话** — 可选，查看其它工作区的历史

会话的消息、工具调用与线程状态保存在本地 SQLite（经 runtime 侧车）。

## 任务类型与会话

切换 **代码 ↔ 办公** 任务类型时，会**开启新会话**，以保证工具面与模型 KV 稳定。工程与文档任务请分开会话。

## 工作区绑定

会话属于当前**工作区路径**。切换目录会切换可见的会话列表。

## 建议

- 首条消息写清目标，长线程更易保持一致。
- 可从侧栏菜单删除不再需要的会话。
- 删除前可 [导出 JSON](/zh-Hans/docs/chat/replay-export) 备查。
