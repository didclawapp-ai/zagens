# 流式输出与停止

Zagens 通过本地 runtime 侧车的 SSE **实时流式**返回助手输出。

## 流式内容

| 类型 | 说明 |
|------|------|
| **正文** | 助手主回复 |
| **思考链** | 可选推理过程（视模型/提供商） |
| **工具调用** | 工具名、参数与进度事件 |
| **工具结果** | 回灌模型的摘要 |

时间线上的工具卡片会显示执行状态。

## 停止生成

回合进行中点击**停止**可取消请求。已输出内容可能保留，可继续追问。

停止**不会**自动撤销已写入的文件 — 需用 [快照](/zh-Hans/docs/workspace/snapshots) 或 git 回滚。

## 连接状态

侧栏显示 **runtime 连接**。若长时间无输出，检查侧车与 API Key。

## 审批中断

部分工具（shell、网络、写入）会弹出**审批对话框**，确认后回合继续。
