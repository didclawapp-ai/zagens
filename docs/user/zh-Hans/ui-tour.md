# 界面导览

Zagens 主窗口可分为三块：**会话侧栏**、**对话区**、**工作区 / 工具面板**。

## 会话侧栏（左侧）

| 入口 | 作用 |
|------|------|
| **新对话** | 在当前工作区开始新会话 |
| **会话列表** | 切换本工作区历史对话 |
| **工作台** | 打开[文件树](/zh-Hans/docs/workspace/file-tree)与预览 |
| **用量** | Token 与费用图表（Settings 内亦有详情） |
| **任务** | 后台任务与技能管理入口（**定时自动化列表当前隐藏**，API 仍保留） |
| **子代理** | CRAFT / 子代理 SSE 状态（代码模式） |
| **清单** | 模型使用长程清单工具时出现（代码模式） |
| **设置** | API Key、MCP、技能、路由、系统项等子面板 |
| **主题 / 语言** | 浅色/深色；四语 UI — 详见[界面语言](/zh-Hans/docs/desktop/i18n) |

侧栏底部可查看与本地 **runtime 侧车** 的连接状态。

## 对话区（中间）

- **输入框** — 描述目标、粘贴 prompt，或在办公空态点击任务卡片
- **流式输出** — 回复、工具调用，以及可选的**思考链**
- **停止** — 取消进行中的回合
- **上下文条** — 当前线程的上下文占用估算

Composer 菜单可**导出会话或线程 JSON**，便于[回放](/zh-Hans/docs/chat/replay-export)或反馈问题。

## 工作区面板（右侧）

**代码**模式常见内容：

- 文件树与**预览**（代码、Markdown、图片、CSV 等）
- 编辑后的 **Diff** 视图
- 绑定工作区目录的**嵌入式终端**（xterm）

**办公**模式侧重**交付物**与 Office 预览；工程向 shell 工具会收束。

## 审计网格（代码模式，可选）

四宫格可同时查看**清单**、**审计 Scratchpad**、**长程任务（LHT）图**、**子代理**状态，适合多步骤工程任务。

## 任务类型

启动时选择**代码**或**办公**会改变可用工具与系统提示。切换任务类型会**开启新会话**，以保持模型上下文稳定。详见[任务类型](/zh-Hans/docs/task-types)。
