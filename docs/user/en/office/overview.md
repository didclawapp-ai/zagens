# Office mode

**Office** task type is a local desktop co-pilot for document-centric work: read spreadsheets, search the web, and deliver **DOCX, XLSX, PPTX, or PDF** — not pasted chat text.

## Workspace layout

See [Office workspace](/docs/office/workspace) for the `inbox/` · `data/` · `deliverables/` layout and [Deliverables preview](/docs/office/deliverables).

Office sessions hide Code-only sidebar entries: **routing**, **topic memory**, **symbol index**, and **LHT settings**.
