Four **P0** end-to-end demos ship with Zagens. Each has a task card on the Office empty state and a dedicated doc page.

All **11 bundled skills** (including weekly report, meeting minutes, and more): [Built-in skills index](/docs/office/skills).

## Try in three steps

1. Download Zagens and choose **Office** task type.
2. Set up an [office workspace](/docs/office/workspace) — copy `inbox/` and `data/` from `docs/harness/fixtures/office-demo/` or the [Use cases](/use-cases) zip.
3. Tap a task card on the empty state or paste the skill prompt from the guide above.

Narrative and marketing context: [Use cases](/use-cases).

**Boundary:** refactors, tests, and shell workflows stay in **Code** mode.
