# Project report (PPT)

**Skill:** `office-project-report` · **Output:** PPTX

## What it does

Creates a slide deck for project status reviews — progress, risks, and next steps.

## Before you start

- Task type: **Office**
- Optional: status docs or prior decks in `inbox/` (DOCX, PPTX, Markdown)

## How to run

1. Tap **Project report PPT** or ask:
   > Create a project status deck. Confirm project name and audience.
2. Provide: project name, presenter, audience, report date, key milestones.
3. Open the PPTX from `deliverables/` in PowerPoint or the Office preview.

## Slides (typical)

**Cover** · progress highlights · risks & mitigation · next steps

## Verify

- Cover slide shows project name and presenter
- Risk slide names concrete mitigations, not generic placeholders

## Tips

- Supply a one-paragraph status in chat if you have no files.
- Ask to add slides: "include a budget slide" — agent updates via `load_office_payload`.
