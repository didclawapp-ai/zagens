# Meeting minutes

**Skill:** `office-meeting-minutes` · **Output:** DOCX

## What it does

Turns meeting notes, transcripts, or slide decks into formal minutes with decisions and **action items** (owner + due date).

## Before you start

- Task type: **Office**
- Optional materials in `inbox/`: DOCX notes, PDF, Markdown, or a pasted transcript in chat

## How to run

1. Tap **Meeting minutes** or ask:
   > Draft minutes for today's sync. Confirm time and attendees first.
2. Provide: meeting time, attendees, agenda topics, key discussion points.
3. DOCX lands in `deliverables/`.

## Output sections (typical)

Basic info · **agenda discussion** · **decisions** · **action items**

## Verify

- Action items list owners and deadlines
- Decisions match what you discussed (no invented agreements)

## Tips

- Dictate rough notes in chat — the skill accepts `dictation` ingest.
- For recurring meetings, reuse the same workspace and reference prior minutes in `inbox/`.
