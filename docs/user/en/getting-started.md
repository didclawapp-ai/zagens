# Getting started

Zagens is a **desktop agent harness** for the DeepSeek V4 ecosystem. One app covers chat, coding, and document workflows — with separate tool surfaces for engineering and office tasks.

## What you need

- Windows 10/11 x64
- A [DeepSeek API key](https://platform.deepseek.com/)
- A folder to use as your workspace (code repo or office inbox)

## First launch

1. [Download](/download) the latest installer.
2. Follow the [install guide](/install) if Windows SmartScreen blocks the unsigned build.
3. Open Zagens (**v0.7.0**), paste your API key, and pick a **task type**:
   - **Code** — terminal, diffs, refactors, tests
   - **Office** — spreadsheets, web research, DOCX / XLSX / PPTX / PDF output

   See [Task types](/docs/task-types) for when to pick each.
4. Select a **workspace folder** for the session.
