# UI language

The Zagens desktop UI supports four locales. This is separate from the language the **agent** replies in (that follows your prompts and model).

## Supported locales

| Language | Code |
|----------|------|
| 简体中文 | `zh-Hans` |
| English | `en` |
| 日本語 | `ja` |
| Português (Brasil) | `pt-BR` |

## How to switch

1. Sidebar → **Settings** → **System**
2. **Appearance** → **Language**
3. Takes effect immediately — no restart required

The sidebar footer also offers a quick **theme / language** toggle (kept in sync with System settings).

## Docs site

This help site ships **English** and **简体中文** product docs; the app UI additionally includes Japanese and Brazilian Portuguese.

## Notes

- Menus, buttons, and settings labels follow the UI locale
- Bundled Office skills and `SKILL.md` bodies are mostly Chinese; you can still prompt in English
- Some runtime logs and errors may stay in English
