# `zagens-agent` (deprecated)

**Status:** Legacy / experimental — **not used** by Zagens or the embedded runtime.

This crate provides `ModelRegistry` with alias-based model resolution. All model selection is now handled via the runtime config and provider system in `crates/config/`. Zero workspace crates depend on this crate.

**Maintainers:** keep the crate in the workspace for historical reference; do not add new consumers.
